The dashboard's dark palette, typography, and card geometry follow [Navet](https://github.com/awesomestvi/navet). The images are rendered with Pillow.

The contribution total, heatmap, active days, streak, and weekly activity use GitHub's public profile calendar. Commit and pull request counts and public repository language totals come from GitHub's API. The dashboard is a daily snapshot; its update date appears beneath the activity chart.

Inter is distributed under the SIL Open Font License; see `assets/fonts/LICENSE.txt`. The bundled TrueType file is converted from Navet's Inter WOFF2 asset.
